# Edufin_Portfolio_Risk_Analysis
## Project Overview

This project focuses on analyzing EduFin's portfolio risk using SQL and Databricks. The objective was to identify default patterns, high-risk customer segments, and key factors contributing to portfolio risk.

## Key Areas of Analysis

- Portfolio Health Analysis
- Customer Risk Analysis
- Time Trend Analysis
- Business Problem Solving
- Identifying High-Risk Segments
- Converting data into actionable business recommendations

## Key Skills

- SQL
- Databricks
- Data Analysis
- Business Analytics
- Risk Analysis
- Data-Driven Decision Making
